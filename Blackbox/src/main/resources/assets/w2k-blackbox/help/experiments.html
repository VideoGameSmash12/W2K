What is being worked on?

A new feature of W2K (compared to W95 and WNT, its predecessors) is an optional, opt-in experiment system. This allows you to continue to run the latest version of W2K without having to sacrifice stability issues that might be caused by unfinished/unstable/untested features that were added to be experimented with.

To enable experiments, you need to add -Dme.videogamesm12.w2k.enabled_experiments= (with the internal names of the experiments in question appended at the end, separated by commas) to your instance's Java launch options. Experimental features can only be disabled by modifying the aforementioned launch options.

The following experiments are currently available at this moment in time:

  • BLACKBOX_HELP_WINDOW

    Offers this help window as a tool in the Blackbox.


  • COMMAND_LINE_LAF_OVERRIDE

    A means to override the theme used by the Blackbox through a command-line parameter.


  • DEFAULT_LAF_BASED_ON_SYSTEM_CONFIG

    Experimental behavior that instructs the Blackbox to use differing defaults for its theme based on your system configuration.


  • EXPERIMENTS_EXISTENCE_ACKNOWLEDGED

    User-facing mentions and interfaces for Experiments through in-game commands.


  • SUPERVISOR_CATCHES_CRASHES

    Crash detection in the Supervisor that catches a standard client crash and prompts the user with the option to view the automatically generated crash report. Might be improved upon later to add more options in the future.
