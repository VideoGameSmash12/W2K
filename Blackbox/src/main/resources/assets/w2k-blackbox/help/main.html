Welcome

Welcome to the Blackbox help window. This tool should provide a comprehensive knowledge base on how to use components of W2K like the Blackbox, Supervisor, Toolbox, and Data Dumper.

Keep in mind that while this tool and W2K's GitHub have a lot of overlap in terms of documentation, neither of them are intended to replace each-other and both have their pros and cons in terms of availability, recency, and more. If you are seeking absolutely up-to-date documentation on this project, please consult the GitHub wiki. If you're looking for an always reliable and purely offline form of documentation, this window is exactly what the doctor ordered.

You can access the online wiki on GitHub at https://github.com/VideoGameSmash12/W2K/wiki/Home.
